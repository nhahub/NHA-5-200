## 2. Component Interface Specifications

| Component | Provided Interface | Required Interface | Description |
| :--- | :--- | :--- | :--- |
| **Auth & Security Controller** | `IAuth` (`register`, `verify_otp`, `login`, `resend_otp`) | `IDatabase`, `ISMTP` | Validates credentials, creates pending accounts, computes bcrypt/SHA-256 hashes, dispatches OTP emails. |
| **Skill Matching Engine** | `IMatch` (`match_skills_and_score`) | `IDatabase`, `ICache` | Reads recent opportunities, executes skill overlap analysis, computes 0–100% scores with written justifications. |
| **AI Proposal Service** | `IProposal` (`generate_proposal`) | `IGLMClient`, `ITemplateFallback` | Integrates with GLM-4 Flash API to craft proposals tailored to target project briefs and freelancer profiles. |
| **Spider Manager** | `ISpiderRunner` (`run_spider`, `run_all`) | `IPipeline` | Asynchronously spawns Scrapy spiders across Mostaql, Khamsat, Nafezly, and Freelancer.com. |
| **PostgreSQL Pipeline** | `IPipeline` (`process_item`) | `IDatabase` | Normalizes scraped records and executes SQL `UPSERT` on the unique URL constraint. |
| **Data Access Object (DAO)** | `IDatabase` (`upsert_project`, `query_projects`, `get_db_health`) | PostgreSQL Driver (`psycopg2`) | Encapsulates SQL transactions, connection pooling, and connection health probes. |
