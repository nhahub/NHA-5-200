# 6.1 RESTful API Documentation
## UNSTUCK – Intelligent Freelance Intelligence Platform
### Interactive Swagger Documentation: `http://localhost:8000/docs`

---

## 1. Overview & General Conventions

- **Base URL:** `http://localhost:8000`
- **Default Content-Type:** `application/json; charset=utf-8`
- **Interactive Documentation:** 
  - Swagger UI: `GET /docs`
  - ReDoc: `GET /redoc`
- **Standard HTTP Status Codes:**
  - `200 OK`: Request succeeded.
  - `202 Accepted`: Asynchronous task initiated.
  - `400 Bad Request`: Validation failure or business rule violation.
  - `401 Unauthorized`: Authentication failed or account unverified.
  - `500 Internal Server Error`: Unhandled database or system exception.

## 2. API Endpoints Specification

### 2.1 System Health & Monitoring

#### `GET /api/db-status`
- **Description:** Checks PostgreSQL connection health and returns active row count.
- **Response `200 OK`:**
```json
{
  "connected": true,
  "total_projects": 842,
  "database": "postgres",
  "host": "localhost",
  "port": 5432
}
```

### 2.2 Opportunities & Search Engine

#### `GET /api/projects`
- **Description:** Retrieves paginated, filterable projects across platforms.
- **Query Parameters:**
  - `platform` (string, optional, default: `"all"`): Comma-separated list (`"mostaql,khamsat"`) or `"all"`.
  - `q` (string, optional): Full-text keyword search across project titles and briefs.
  - `limit` (integer, optional, default: `200`, min: `1`, max: `1000`).
  - `offset` (integer, optional, default: `0`).
- **Response `200 OK`:**
```json
{
  "source": "postgresql",
  "total": 148,
  "count": 50,
  "projects": [
    {
      "id": 12,
      "platform": "Mostaql",
      "platform_key": "mostaql",
      "title": "Build Intelligent Dashboard in React & FastAPI",
      "url": "https://mostaql.com/projects/12345",
      "price": "$150.00 - $300.00",
      "duration": "5 Days",
      "published_at": "20 minutes ago",
      "brief": "Seeking an experienced developer to connect a React interface with FastAPI and PostgreSQL.",
      "requirements": ["React", "FastAPI", "PostgreSQL", "Python"],
      "scraped_at": "2026-11-06T23:30:00Z",
      "updated_at": "2026-11-06T23:40:00Z"
    }
  ]
}
```

### 2.3 Intelligent Matching & Proposal Synthesis

#### `POST /api/match`
- **Description:** Evaluates scraped opportunities against a user's skills and computes a 0–100% fit score with justification reasons.
- **Request Body:**
```json
{
  "user_skills": ["React", "Python", "FastAPI", "Tailwind", "PostgreSQL"],
  "platform": "all",
  "limit": 20
}
```
- **Response `200 OK`:**
```json
{
  "status": "ok",
  "total": 20,
  "user_skills": ["React", "Python", "FastAPI", "Tailwind", "PostgreSQL"],
  "jobs": [
    {
      "id": 12,
      "title": "Build Intelligent Dashboard in React & FastAPI",
      "platform_key": "mostaql",
      "match_score": 96,
      "matched_skills": ["React", "FastAPI", "PostgreSQL", "Python"],
      "missing_skills": [],
      "reasons": [
        "Excellent match with core competencies: React, FastAPI, PostgreSQL, Python",
        "100% of required job skills align with your Freelance DNA profile"
      ]
    }
  ]
}
```

### 2.4 Authentication & Email Verification

#### `POST /api/auth/register`
- **Request Body:**
```json
{
  "full_name": "Aya Elsayed",
  "email": "user@example.com",
  "password": "StrongPassword@2026"
}
```
- **Response `200 OK`:**
```json
{
  "success": true,
  "message": "User registered. Verification OTP sent via email.",
  "email": "user@example.com"
}
```

#### `POST /api/auth/verify-otp`
- **Request Body:**
```json
{
  "email": "user@example.com",
  "otp": "482915"
}
```
- **Response `200 OK`:**
```json
{
  "success": true,
  "message": "Account successfully verified."
}
```

#### `POST /api/auth/resend-otp`
- **Request Body:**
```json
{
  "email": "user@example.com"
}
```
- **Response `200 OK`:**
```json
{
  "success": true,
  "message": "New OTP sent to email."
}
```

#### `POST /api/auth/login`
- **Request Body:**
```json
{
  "email": "user@example.com",
  "password": "StrongPassword@2026"
}
```
- **Response `200 OK`:**
```json
{
  "success": true,
  "user": {
    "id": 1,
    "full_name": "Aya Elsayed",
    "email": "user@example.com",
    "is_verified": true
  }
}
```

### 2.5 Admin Operations & Web Crawling

#### `POST /api/scrape`
- **Query / Body:** `?wait=false` or `{ "platforms": ["all"], "wait": false }`
- **Response `202 Accepted`:**
```json
{
  "message": "started",
  "target": "all"
}
```

#### `POST /api/sync-json-to-db`
- **Description:** Reads all JSON files in `output/` and executes atomic PostgreSQL `UPSERT` operations.
- **Response `200 OK`:**
```json
{
  "success": true,
  "total_synced": 842,
  "inserted": 35,
  "updated": 807
}
```
